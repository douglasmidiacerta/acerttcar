# Acertt AI Monitor — Android

Aplicativo nativo de monitoramento local do Samsung Galaxy S20 FE. Os comandos usam a permissão oficial RUN_COMMAND do Termux. Não há chaves ou senhas no código.

O projeto-fonte está no arquivo `android-source.b64` (ZIP codificado em Base64). O GitHub Actions recompõe os arquivos e gera o APK de testes na aba Actions.

**Atenção:** versões de teste, ainda precisam ser validadas no Galaxy S20 FE. O monitor mostra status e logs, mas não corrige sozinho falhas internas do WAHA ou da IA.
